# generated

このディレクトリのファイルは `npm run gen` が `dict/*.yml` から生成する。直接編集しない。

`.patterns` は `rg --file` にそのまま渡す。ripgrep は行を無条件にパターンとして読むため、
コメント行と空行を書けない。空行は「すべてに一致する空パターン」になり、
検査結果が空文字列で埋まって実質無効化される。

| ファイル | 中身 | 使う場所 |
| --- | --- | --- |
| `all.patterns` | 両方の辞書の全パターン | 手元での確認用 |
| `chat.patterns` | `scope: chat` を付けた規則だけ | Stop フック（会話出力の検査） |

辞書を編集したら `npm run gen && npm test` を実行し、生成物も一緒にコミットする。
`npm test` は生成物と辞書のずれを検出するので、コミットし忘れると気づける。
