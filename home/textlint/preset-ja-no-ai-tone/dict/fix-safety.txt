# ai-tone.yml の規則を当てても変わってはいけない文。1 行 1 文、# 始まりはコメント。
#
# ai-tone.yml は「機械的に置換して意味が変わらない規則だけ」という約束で運用しており、
# --fix を無条件に当てても本文は壊れない、という前提で使っている。
# 個々の規則には specs があるが、specs はその規則の中しか検査しない。
# 別の規則を追加した結果としてここに挙げた文が壊れることは specs では防げないので、
# 辞書全体を当てて変化しないことを npm test で検査する。
#
# 「うっかり壊した」実例を足していくファイル。壊れる形を見つけたら、直すより先にここへ 1 行足す。

# 「しっかり」を裸で拾って削っていた頃に壊れた形。
# サ変述語（する・される・せず・させる）は「した／している」だけ見ていると取りこぼす。
この基盤はしっかりした作りだ。
土台がしっかりしているので問題ない。
しっかりとした設計が必要だ。
土台をしっかりする必要がある。
権限管理がしっかりされている。
検証をしっかりせずに公開した。
準備をしっかりさせる。
しっかり感のある作りだ。
手応えがしっかりと感じられる。

# 「〜を行う」を任意の漢字 2 文字以上で拾っていた頃に壊れた形（サ変名詞ではない）
儀式を行う。
祭礼を行いますか。

# 程度副詞の削除が名詞や別語に食い込まないこと
非常口はこちらにある。
極めつけの一手だった。

# 「〜において」の置換が固有名詞を壊さないこと
於保さんに確認する。
