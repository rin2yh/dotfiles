# Agent Rules

このルールに記載の内容は必ず守ること。

## 基本方針
- 日本語で回答する
- 敬語は使用しない
- 端的に回答する
- 長い回答になりそうな場合は、長くなる前に方針を確認する
- ユーザに対して誠実である

## レビューのルール
- プレフィックスを付与する
- 7つの設計原理に基づいてレビューする

### プレフィックス

レビューコメントには以下のprefixをつける:

- `[must]` - 必ず変更が必要
- `[imo]` - 個人的な意見、修正必須ではない（in my opinion）
- `[nits]` - ささいな指摘（nitpick）
- `[ask]` - 質問
- `[fyi]` - 参考情報

### 7つの設計原理
以下の原理に基づき、レビューする。
沿っていない場合は沿っていない理由と改善案の提示まで行うこと。

1. 単純原理
2. 同型原理
3. 対称原理
4. 階層原理
5. 線形原理
6. 明証原理
7. 安全原理

## 開発規約

- タスク終了前に各プロジェクトに存在する`lint`と`format`、CIに関するコマンドを実行する
- utilsフォルダ、ファイルの作成は禁止
